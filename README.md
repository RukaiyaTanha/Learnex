# Learnex | AI-Based Smart Class Performance Tracker

**Learnex** is an AI-assisted smart classroom platform designed to support continuous academic performance monitoring and personalized learning. It allows students to take AI-generated assessments, track their academic progress, identify weak topics, and receive personalized feedback based on their learning performance.

The system also provides teachers with tools to monitor student performance, track learning progress, and identify students who may need additional academic support.

## Key Features

### 1. AI-Powered Assessment
- Generate quizzes and assessments dynamically using the Google Gemini API.
- Create topic-based questions from uploaded course materials and syllabus content.
- Automatically evaluate student answers and provide feedback.
- Support additional practice and self-assessment.

### 2. Student Dashboard
- View assigned courses and course information.
- Take AI-generated quizzes and practice assessments.
- Track assessment history and class marks.
- Monitor academic performance and improvement trends.
- Identify weak topics and receive personalized learning recommendations.
- Upload and access course notes and syllabus materials.

### 3. Teacher Dashboard
- Monitor student academic performance.
- Track assessment results and learning progress.
- Review student performance across different topics.
- Receive notifications when students repeatedly achieve low assessment scores.

### 4. Performance Analytics
- Visualize academic performance through interactive charts.
- Track topic-wise assessment results.
- Identify learning patterns and areas requiring improvement.
- Monitor overall academic progress over time.

### 5. Additional Learning Tools
- AI Learning Assistant for course-related questions and explanations.
- CGPA calculator.
- Study tools and academic utilities.
- Course material management through PDF uploads.

## System Workflow

1. Teachers manage course information and provide learning materials.
2. Students access their assigned courses and upload relevant study materials.
3. The system uses the Gemini API to generate topic-based assessments.
4. Students complete assessments and receive automatically evaluated results.
5. The system identifies weak areas and provides personalized feedback.
6. Students and teachers monitor academic performance through their respective dashboards.
